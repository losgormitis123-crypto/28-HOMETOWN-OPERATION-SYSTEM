# 四条内容主线

## 1. 最后一代放牛娃

讲述小时候放牛的经历、童年记忆、农村成长、艰苦生活。

示例：

- 小时候放牛最怕什么？
- 放牛娃长大后去了哪里？
- 那头牛陪我走过了整个童年。
- 小时候想逃离农村，长大后却开始怀念农村。

## 2. 湖北老家来信

姐姐、哥哥、家人发来的家乡素材。

示例：

- 姐姐今天发来一段黄牛吃草的视频。
- 哥哥又去放羊了。
- 老家的山坡还是小时候的样子。
- 一年只能回家两次，但家乡每天都在发生变化。

## 3. 42岁学AI

普通父亲借助AI成长、学习、搭建系统、改变命运。

示例：

- 我42岁才开始认真学习AI。
- AI不是工具，是普通人重新选择人生的机会。
- 工厂下班后，我开始搭建自己的AI系统。
- 我不是为了成为专家，而是为了不再被动接受命运。

## 4. 留给孩子的数字家书

写给孩子看的内容，让孩子看到父亲的来处、成长、努力和家乡。

示例：

- 孩子，这是爸爸小时候放牛的地方。
- 你今天看到的黄牛，是爸爸童年的一部分。
- 爸爸希望你看到农村，也看到改变命运的可能。
- 爸爸不是想让你吃苦，而是希望你知道生活本来的样子。
