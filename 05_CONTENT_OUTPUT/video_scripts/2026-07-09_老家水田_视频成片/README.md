## 说明

当前电脑没有可用的 `ffmpeg`，苹果自带转换工具也没有成功把 AVI 转成 MP4。

所以这次先生成了一个竖屏字幕版 AVI 视频。

如果要发抖音，建议把下面三个文件导入剪映：

1. 字幕版视频
2. 字幕 SRT
3. 口播纯文本

然后用自己的声音录一遍口播，效果会比系统朗读更真实。
