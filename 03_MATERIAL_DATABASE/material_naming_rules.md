# 素材命名规则

命名格式：

```text
日期_地点_主体_场景_拍摄人.后缀
```

示例：

```text
2026-06-01_湖北老家_黄牛_山坡吃草_姐姐.mp4
2026-06-01_湖北老家_羊群_回家路上_哥哥.mp4
2026-06-01_童年回忆_小时候放牛怕下雨_自己.md
2026-06-01_发布数据_小红书第一篇_自己.png
```

## 使用建议

1. 日期尽量使用素材真实日期。
2. 地点尽量写清楚，比如湖北老家、老屋门口、山坡、田边。
3. 主体写画面里最重要的对象。
4. 场景用大白话描述，不要太长。
5. 拍摄人写姐姐、哥哥、自己或其他。
